# 브랜드 원안 (백업)

**이것이 원본이다.** 화면에 쓰는 것은 여기서 줄이고 잘라 낸 사본이고,
`apps/web/public/brand/` 와 `apps/web/src/app/` 에 있다.

원본을 저장소에 두는 이유: 자산이 만들어진 곳(별도 작업 공간)은 언제든 사라질 수 있는데,
**줄인 사본만 남으면 다시 크게 만들 수 없다.** 화면 크기가 바뀌거나 인쇄물이 필요해지면
여기서 다시 뽑는다.

### 어드민 배너는 둘 중 하나만 쓴다

`-01` 과 `-02` 는 둘 다 브랜드 파랑에 정장 고양이다. **`-02` 를 골랐다** — `-01` 은 같은
구도인데 그림 속 카드가 더 커서 배너를 줄이면 먼저 뭉갠다.
**고르지 않은 `-01` 도 지우지 않는다.** 화면 구성이 바뀌면 다시 고를 수 있다.

전에 `banner/admin-03.png` 였던 민트 그림은 **어드민이 아니라 슬라이드쇼 3번째**였다.
이름이 잘못 붙어 어드민 후보로 분류돼 있던 것을 `banner/submissions-03.png` 로
옮겼다 (#518).

### 고양이 캐릭터 원안은 `source/` 다

앞·옆·뒤 6면 시트라 **화면에 쓸 자세가 아니다** — `character/01`~`04` 를 안 쓰는 것과
같은 이유다. 캐릭터를 다시 그리거나 새 자세가 필요할 때 넘겨주는 기준 그림이라
`brand-sheet-original.png` 옆에 뒀다.

## 화면용으로 바꿀 때 한 일

`apps/web/public/brand/README.md` 에 어느 원본이 어느 파일이 됐는지 적어 두었다. 요약하면:

1. **흰 배경 제거** — 테두리에서 흘려보내는 방식(flood fill)이다. "흰 픽셀 = 배경" 으로
   지우면 캐릭터의 흰 머리·흰 운동화까지 뚫린다
2. **투명 여백 잘라내기** — 원본은 패딩이 40~70% 라 그대로 넣으면 화면에서 작아 보인다
3. **가짜 UI 잘라내기** — 500 의 "TRY AGAIN", 403 의 "로그인 하기" 처럼 **그림 속 버튼**은
   눌리지 않아 함정이 된다. 그 부분을 뺐다
4. **WebP 로 줄이기** — 원본 합계 38MB, 화면용 합계 1MB 미만

이 과정은 손으로 했다. 자산이 다시 그려지면 같은 판단을 다시 해야 한다 —
**자동화하지 않은 이유는 판단이 매번 다르기 때문이다** (어디를 자를지는 그림마다 다르다).
